Open **Courses**, choose a course, and select a lesson to reach the block editor. Type `/` anywhere in the editor to search for a block by name. Every block can be moved with the drag handle that appears on its left side when you hover over it.

## Inserting and reordering blocks

Type `/` at the start of any line to open the block menu. Start typing the name of the block you want and press **Enter** to insert it. To move a block, grab the drag handle on its left edge and drop it where you want it. The drag handle also opens a menu with **Duplicate**, **Copy**, **Paste**, and **Delete**, so a block can be copied from one lesson and pasted into another. As you browse the slash menu, a side card shows a small wireframe of how each block renders for students, so you can pick the right one before inserting it.

<Tip>
  You can reorder any block type, including interactive learning blocks and media embeds, using drag-and-drop. The handle appears when you hover over the block's left margin.
</Tip>

## Embed a website

Type `/` and choose **Embed** (searching "iframe" finds it too). The block shows **Embed a website or interactive experience**; click it to open the form.

1. On the **Link** tab, paste the published page URL. Only secure (`https://`) addresses work, and the site must allow being embedded.
2. Give it a **Title**. The title is required, because screen readers announce it to students. It starts as "Embedded content".
3. Set the **Height (px)**, between 240 and 1200 pixels. The default is 480.
4. Click **Embed link**. Fayne checks the URL first and tells you if the page can't be found or the site doesn't allow embedding.

YouTube and Vimeo links are sent to the **Video** block instead. The **Upload** tab turns the block into a file download.

Once the embed is in place, click **Edit embed** under it to change the URL, title, or height. **Open in new tab** opens the original page.

## Beyond blocks

A lesson also carries a few attachments that live outside the block canvas, in the action bar above the editor:

- **Add video** promotes a video to the lesson's hero, shown at the top of the lesson.
- **Generate Audio** creates a read-aloud version of the lesson in a catalog voice or your own cloned voice. See [Lesson audio](/content/lesson-audio).

For structuring a whole course rather than a single lesson, see [Modules](/content/modules), [Knowledge checks](/content/knowledge-checks), and [Drip scheduling](/content/drip-scheduling).
